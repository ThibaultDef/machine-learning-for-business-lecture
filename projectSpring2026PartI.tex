\section*{Project Description}

Predict house prices in different communities based on air pollution level (nitrogen oxide concentration), distance from employment centers, student-teacher ratio, average number of rooms, and crime rate.

\subsection*{Variables}
\begin{itemize}
  \item \textbf{price:} median housing price
  \item \textbf{crime:} crimes committed per capita
  \item \textbf{nox:} nitrogen oxide, parts per 100 million
  \item \textbf{rooms:} average number of rooms per house
  \item \textbf{dist:} weighted distance to 5 employment centers
  \item \textbf{stratio:} average student-teacher ratio
  \item \textbf{lprice:} $\log(\text{price})$
  \item \textbf{lnox:} $\log(\text{nox})$
\end{itemize}

Data file: \lstinline|hprice2_merged.csv|

\subsection*{Tasks}

\begin{enumerate}
  \item Randomly select two sets of 100 data points. Compute mean, variance, and histogram for $lprice$, $lnox$, $rooms$, $dist$, and $crime$. Are values similar? Can we assume independent and identically distributed variables? Use hypothesis testing to compare distributions.
  
  \item Fit linear regression models using subsets of $\{lnox, dist, rooms, stratio, crime\}$ to predict $lprice$. Reserve at least 20\% of data for validation.
  
  \item Calculate $R^2$ scores for each model. Comment on model quality. Are independent variables linearly independent? Which variables are most relevant for predicting $lprice$ and why?
  
  \item Evaluate confidence intervals for regression parameters for each model. Are all coefficients statistically significant? Explain.
  
  \item Fit a model using $lnox$, $dist$, $rooms$, $stratio$, and $\log(nox^3 e^{dist+1})$ to predict $lprice$. Compute confidence intervals. Compare variable significance with Step 2. Is there multicollinearity?
  
  \item Repeat Steps 2--5 predicting $price$ instead of $lprice$.
\end{enumerate}
