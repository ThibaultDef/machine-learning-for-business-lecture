
A l’issue de ce cours, les participants auront développé 
leur capacité à : 
•	Connaître les fondamentaux du Machine Learning
•	Connaître les différents types d'algorithmes de Machine Learning
•	Connaître les principale mesures de performance des algorithmes de Machine Learning
•	Comprendre les concepts principaux autour du Machine Learning
•	Comprendre du code écrit avec la librairie Scikit-Learn



Les participants développeront une compréhension solide des fondamentaux du Machine Learning et apprendront à évaluer rigoureusement les modèles ML.

Ce cours combine théorie et pratique en utilisant les bibliothèques statistiques et de machine learning Python (notamment Scikit-Learn) sur des ensembles de données réels.

Sujets couverts :
- Fondamentaux des probabilités et statistiques appliqués à l'apprentissage statistique
- Algorithmes d'apprentissage supervisé et non supervisé
- Fondamentaux de la régression et classification
- Évaluation de performance et validation de modèle statistiquement rigoureuses
